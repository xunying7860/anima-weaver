# Anima Weaver

<p align="right">
  <b>中文</b> | <a href="README.md">English</a>
</p>

一个 ComfyUI 自定义节点包，基于结构化方式组装 AI 图像生成提示词，支持标签/自然语言混合输出、批量管线、随机画师与随机分辨率。

---

## 节点列表

| 节点 | 分类 | 用途 |
|------|------|------|
| **Anima随机提示词** | Anima Weaver | 主节点：组装标签 → NL → 完整提示词（两级分组控件，内置随机种子） |
| **随机分辨率选择器** | Anima Weaver | 随机生成宽高比/分辨率文本（内置随机种子） |
| **批量种子** | Anima Weaver / Batch | 生成 N 个种子（上限 4096），供跨节点对齐共用；也是主节点内置种子的替代方案（跨节点对齐时用）；主节点单独批量可用「批量数量」控件替代 |
| **Anima批量合并** | Anima Weaver / Batch | 4 路多行串（种子/提示词/宽度/高度）按行对齐 → 合并输出 JSON 多行 |
| **Anima批量拆分** | Anima Weaver / Batch | 一行 JSON（上游用 easy-use「提示词行」选出）→ 种子/提示词/宽度/高度 标量 |

> 2026-10-16 起 8 → 4 → 5 节点：Anima反推、画师Seed、Anima加载图像、Anima列表转多行 已删除；
> 批量总线拆回 **Anima批量合并 + Anima批量拆分** 两节点（标准管线：合并 → easy-use 提示词行 → 拆分）。
>（画师能力并入主节点「画师种子」控件，画师名直接拼进提示词末尾；反推/分辨率通道已裁剪）。
> laya 微调脚本（`laya_finetune.py`）与训练数据（`data/laya_n2/`）一并移除，
> 可在 `pre-4node-20261016` tag 找回。

## 安装

### 前提

- [ComfyUI](https://github.com/comfyanonymous/ComfyUI)
- 可选：[LM Studio](https://lmstudio.ai/)（用于 NL 增强模式）

### 步骤

1. 克隆或复制本仓库到 ComfyUI 的 `custom_nodes` 目录：
   ```bash
   cd ComfyUI/custom_nodes
   git clone https://github.com/xunying7860/anima-weaver.git
   ```

2. 安装依赖：
   ```bash
   pip install requests
   ```

3. 安装前置依赖：[ComfyUI-Easy-Use](https://github.com/yolain/ComfyUI-Easy-Use)（批量管线必需）
   ```bash
   cd ComfyUI/custom_nodes
   git clone https://github.com/yolain/ComfyUI-Easy-Use.git
   ```

4. 重启 ComfyUI。

> **标签库（约 215 MB）**：`git clone` 方式需运行 `python download_tags.py` 下载约 215 MB 标签库；
> 直接下载 Release zip 解压即用。未下载时「随机/混合」模式的抽签为空（节点照常运行，
> 提示词只含手填部分）。

<img width="2471" height="1624" alt="image" src="https://github.com/user-attachments/assets/523fff97-7b53-4f9c-ad8a-041d82918363" />


### Anima随机提示词

三种工作模式（选项值已改官方中文用语，旧英文值 `manual`/`random`/`hybrid` 自动兼容）：

| 模式 | 说明 |
|------|------|
| `手动` | 手填 8 个插槽标签输出 |
| `随机` | 从 40 万条 Danbooru taglist 中随机抽取 |
| `混合` | 随机填充 + 手填标签追加，互斥时保留手填的 |

**标签比例**滑块控制输出中标签与自然语言的比例（0.0=纯自然语言 ↔ 1.0=纯标签）。

支持 LM Studio NL 增强，调用本地 LLM 将标签转为英文描述。

**内置随机种子：** 主节点内置 `随机种子` widget（`control_after_generate`，可 randomize / increment）：
`0`=每次执行内部随机；`>0`=确定性复现。批量模式下接了 `种子串` 则内置种子让位；
只设「批量数量」时内置种子升级为**父种子**，派生 N 个可复现子种子
（旧版「批量数量」走 `random.randint`，同参数每次跑出不同的一批，现已可复现）。

| 项 | 内置随机种子（widget） | 种子串（输入端口，「高级 ▸ 批量」下） |
|----|------------------------|--------------------------------------|
| 来源 | 节点自身 INT 控件，`control_after_generate=True` | 外部「批量种子」/总线拆分接入，多行 |
| 取值 | `0` = 每次执行内部随机；`>0` = 确定性复现 | 每行一个种子 |
| 单次模式 | 唯一随机源：驱动抽签 / 槽位抽样 / 画师子流 | 不接 |
| 批量：接了种子串 | **不参与**（种子串逐行接管，行为同旧版） | 每行一个独立种子 |
| 批量：只设「批量数量」 | 升级为**父种子**：派生 N 个可复现的子种子 | 不接 |
| 优先级 | 种子串非空 → 内置种子让位 | 非空即接管 |

**两级分组：** 控件收进两级折叠组（一级组：标签槽位 / 过滤控制 / 高级；「高级」下挂四个二级组）：

```
[一级常驻]
  模式 · 标签比例 · 随机种子（内置 widget，可 randomize / increment）
▸ 标签槽位            ← 一级组
    人数/身份 外貌 服装 姿势/动作 表情 镜头 场景/环境 细节/氛围 自然语言描述
▸ 过滤控制            ← 一级组
    标签列表必含 过滤标签 排除含标签列表 排除标签分类 通用/争议/敏感/露骨
▸ 高级                ← 一级组（父）
    画师种子 · 冲突检查
    ▸ LLM设置         ← 二级组（父关则整组消失）
        自然语言来源 强制详细自然语言 模型 API地址 API密钥 云端模型名
        上下文长度 自动上下文长度 最大截断长度 生成后卸载
    ▸ 批量            ← 二级组
        批量数量 请求数 最大并发数 + [种子串] 端口
    ▸ laya判定        ← 二级组
        启用laya门控 过滤质量标签
    ▸ 系统提示词      ← 二级组（新增，可开关）
        系统提示词（可手填） 详细NL系统提示词（可手填）
```

`▸ 高级` 关闭 → 四个二级组连同控件全部隐藏；`▸ 高级` 打开 → 显示四个子开关
（默认全关），子开关打开才显示其成员。

**系统提示词组：** 「系统提示词」由 forceInput 端口改为可开关、可手填的多行控件
（放在「▸ 系统提示词」二级组内）：留空=用内置默认提示词；手填一段则覆盖默认 NL 生成提示词。
「详细NL系统提示词」仅在「强制详细自然语言」开启时生效，留空回落默认详细提示词。

**批量模式：** 接入 `种子串`（批量种子节点的输出）后，每种子独立 Raffle + NL 生成。LLM 加载一次，然后 N 组请求并发执行，全部完成后按需卸载。

**并发批量 LLM：** 支持 `请求数`（默认 4）和 `最大并发数`（默认 4）参数。模型加载一次，然后 N 个线程同时发 HTTP 请求，本地 LM Studio 和云端 API 均适用。`自动上下文长度` 开启后自动计算上下文 = 最大并发数 × 2048（仅本地模型有效）。

**冲突检查：** 内置 23 对互斥表，自动检测冲突标签并移除 Raffle 来源的冲突项，保留手动标签。

**画师（画师种子）：** `-1`=随机画师 / `0`=无画师 / `1~`=固定画师序号。
画师名直接拼进提示词末尾，**没有单独的画师串输出**（原画师Seed 节点已删除）。

| 参数 | 类型 | 说明 |
|------|------|------|
| 模式 | 下拉 | 手动 / 随机 / 混合（旧英文值自动兼容） |
| 标签比例 | 滑块 | 标签与自然语言比例（0.0–1.0） |
| 随机种子 | 整数 | 内置种子：0=每次执行内部随机，>0=确定性复现；批量模式接了种子串则让位，只设批量数量时作父种子 |
| 自然语言来源 | 下拉 | 手动 / LM Studio（旧英文值自动兼容） |
| 强制详细自然语言 | 开关 | 强制 NL 非常详细（512 tokens） |
| 模型 | 下拉 | LM Studio 模型选择（选 `none` 禁用 LLM，透传变化文本） |
| 生成后卸载 | 开关 | 生成后卸载模型 |
| API地址 | 文本 | LM Studio / OpenAI 兼容 API 地址 |
| API密钥 | 文本 | API 密钥（本地留空） |
| 云端模型名 | 文本 | 云端模型名（填密钥后覆盖本地模型） |
| 上下文长度 | 整数 | 上下文窗口大小（0–262144，默认 8192） |
| 自动上下文长度 | 开关 | 自动计算上下文 = 最大并发数 × 2048（仅本地） |
| 请求数 | 整数 | 生成请求数量（1–128，默认 4） |
| 最大并发数 | 整数 | 最大并发预测/线程数（1–128，默认 4） |
| 最大截断长度 | 整数 | 最大输出 token（0=自动 256/512，8–1080） |
| 画师种子 | 整数 | -1=随机画师，0=无画师，≥1=固定画师序号 |
| 冲突检查 | 开关 | 开启冲突检测 |
| 系统提示词 | 多行文本 | 自定义系统提示词（「▸ 系统提示词」组内，可手填；留空=内置默认） |
| 详细NL系统提示词 | 多行文本 | 仅「强制详细自然语言」开启时使用；留空回落默认详细提示词 |

**输出：**

| 输出 | 类型 | 说明 |
|------|------|------|
| `生成的提示词` | STRING | 最终组合的提示词（画师名已拼在末尾） |
| `调试信息` | STRING | 模式、种子、冲突检查结果等 |

### 随机分辨率选择器

生成随机分辨率的独立节点。

#### 手动模式
- 保留原有全部功能，从 13 种比例下拉选择或随机

#### 自动模式
- 「模式」开启后按种子在 13 种比例中随机选择（忽略固定比例）
- 评分制决策引擎 v7（7 层归一化 + 三维评分）仍保留在模块内；「提示词」输入端口
  已按用户要求移除，需要按构图分析选比例时可用 `analyze_prompt()` 自行接入

**内置随机种子：** 节点内置 `随机种子` widget（`control_after_generate`）：
`0`=每次随机 / `>0`=按此种子确定性选画幅；接了「种子串」则内置种子让位（仅作无串兜底）。
输出共 3 槽：「种子串」（未接时为空串）+「宽度」「高度」——宽/高为通配类型 `*`：
**未接种子串时返回 int 整数**（可直接连空Latent 等 INT 输入），接了种子串时返回逐行多行字符串。
（「随机种子」输出槽与「提示词」输入端口已按用户要求删除，评分引擎保留在模块内备用。）

**支持 13 种比例：** 1:1, 2:3, 3:2, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9

**评分机制（宽屏/竖屏/方屏三维评分）：**
- **宽屏因子：** 战斗(+3)、动作(+2)、过肩镜头(+3)、广角(+2~3)、航拍(+2~4)、小群体(+1)、大群体(+5)、多人数(+2)、全景(+5)、全身+多人(+2)、对抗(+1)、躺卧(+2,覆盖坐姿)、拥抱+群像(+2)、仰拍(+1)
- **竖屏因子：** 竖长构图(+4~1)、自拍(+4)、全身+单人(+2)、半身/胸像(+1)、上半身/下半身(+2)、坐姿(+3)、蜷缩(+1)
- **方屏因子：** 面部特写(+5)、焦点细节(+5)、Q版(+4)、美式镜头(+3)、静物(+2)、俯拍(+1)
- **组合加分：** fighting+action(+1)、panorama+wide(+1)、full body+action(+1)

**覆盖的构图场景：**
- 单人/双人/小群(3-4人)/大群(5+)
- 站立/坐姿/躺卧/蜷缩
- 面部特写/半身/全身
- 拥抱/家庭群像/战斗/动作/杂技
- POV/过肩镜头/自拍
- 全景/广角/航拍
- 静物/产品摄影
- 各种角度（仰拍/俯拍/平视）

**7 层优先级归一化：**
- Layer 0: 复合词优先（避免 face close up 被 close up 污染）
- Layer 1: 人数与群体
- Layer 2: 景别与镜头
- Layer 3: POV 视角
- Layer 4: 动作与姿态
- Layer 5: 面部与焦点
- Layer 6: 场景与环境
- Layer 7: 角度

**输出（3 槽）：**
- 种子串（STRING，未接为""）· 宽度（*）· 高度（*）
- 未接种子串：宽/高为 **INT 整数**；接了种子串：宽/高为逐行多行字符串

**分辨率计算：**
- 全局最小边 512px，最大边 2048px
- 对齐步长 16（适配 Illustrious / anima-base DiT）
- 面积损失 < 3%

### 批量种子

生成 N 个随机种子供批量管线使用（上限 4096）。
也是主节点内置种子的替代方案（跨节点对齐时用）：需要提示词/分辨率/采样器共用同一批种子时，
接「批量种子」输出到各节点的「种子串」端口即可；不接时主节点可用内置种子 + 「批量数量」自动派生。

### Anima批量合并

将 4 路多行 STRING（种子串/提示词串/宽度串/高度串）按行对齐合并为 JSON 多行
（每行一个完整数据组），支持行窗口参数。下游接 easy-use「提示词行」选出单行，
再喂给「Anima批量拆分」。

| 参数 | 说明 |
|------|------|
| `start_index` | 起始行号 |
| `max_rows` | 最大输出行数 |
| `remove_empty_lines` | 是否移除空行 |

**输出格式（每行一个 JSON）：**
```json
{"种子":"42","提示词":"1girl,solo...","宽度":"1024","高度":"768"}
```

### Anima批量拆分

接收「提示词行」选出的单个 JSON 行（直接喂多行时取窗口第一行），拆回 4 路标量：

| 输出 | 类型 |
|------|------|
| 种子 | INT |
| 提示词 | STRING |
| 宽度 | INT |
| 高度 | INT |

> 旧「同步串行/串行拆分」「Anima批量总线」均由 `tools/migrate_workflows.py` 自动迁移。

## 批量管线架构

```
批量种子(N个)   ← 可省略：主节点内置种子 + 「批量数量」可自动派生 N 个可复现子种子
  │ 种子串 STRING (N行)
  ├──→ 随机分辨率选择器 → 宽度串/高度串
  ├──→ Anima随机提示词 → 提示词串（画师已并入提示词，不再单独成列）
  │
  ▼
Anima批量合并 ──JSON多行──→ 提示词行(easy-use) ──单行JSON──→ Anima批量拆分
                                                          │ 种子(INT) → KSampler
                                                          │ 宽度(INT) → 空Latent
                                                          │ 高度(INT) → 空Latent
                                                          │ 提示词(STR) → CLIP
```

每种子独立 Raffle + NL，LLM 加载一次，N 组并发执行（通过 `请求数` 和 `最大并发数` 控制，默认均为 4），跑完后按需卸载，统一进入采样器采样，不额外占用显存。
种子串现在可由主节点内置种子派生，不必外挂「批量种子」节点；需要跨节点对齐（提示词/分辨率/采样器同种子）时再接「批量种子」。
